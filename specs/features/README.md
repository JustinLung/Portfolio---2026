# Feature specifications

Create one file per feature by copying
[`../04_workflows/feature-spec-template.md`](../04_workflows/feature-spec-template.md).

Use the filename format:

```text
YYYY-MM-DD-kebab-case-feature.md
```

Keep completed specifications in this directory as durable records of intent and verification.

Shipped routes (home, work, writing, about, contact, legal) predate this folder. Do not backfill
specs for them; start a new file for the next change that alters behavior, data contracts, or
visitor-facing experience.
